# 06_package — Paket Submit

Folder ini berisi bahan pendamping untuk pengumpulan tugas: manifest, pemetaan klaim, surat pengantar, kandidat jurnal, catatan kontribusi, data mentah bentuk tabel, dan slide.

| Berkas | Isi |
|---|---|
| `MANIFEST.md` | Daftar lengkap isi paket submit dan keterangannya. **Mulai dari sini.** |
| `claims_evidence.md` | Pemetaan setiap klaim naskah ke bukti eksekusi dan cara memeriksanya. |
| `cover_letter.md` | Draf surat pengantar submission. |
| `journal_candidates.md` | Dua kandidat jurnal beserta alasan kesesuaian dan tautan resmi. |
| `member_contributions.md` | Pembagian kontribusi anggota dan artefak yang dapat diperiksa. |
| `slides_kelompok1.pptx` | Slide presentasi kelompok. |
| `raw_results/main_runs.csv` | Rekaman run utama dalam bentuk tabel. |
| `raw_results/pilot_runs.csv` | Rekaman run pilot dalam bentuk tabel. |
| `raw_results/ablation_runs.csv` | Rekaman run ablation dalam bentuk tabel. |
| `raw_results/all_runs.xlsx` | Gabungan seluruh run dalam Excel. |

## Catatan

- `MANIFEST.md` adalah rujukan utama; README ini hanya ringkasan.
- `raw_results/` adalah ekspor dari `03_experiments/raw/*.jsonl`, dibuat oleh `02_code/export_raw.py`.
- Naskah utama untuk submit adalah versi Inggris di `05_manuscript/`; versi Indonesia di `05_manuscript/idn/` adalah pendamping.
